`tynys/geology.py` проверяет контрольные суммы при первом чтении. `model()`
воспроизводимо строит 60 представительных мест по всем пробам измельчения:

- BWi = 49 / [A^0,23 × M^0,82 × (10/√P80 − 10/√F80)], кВт·ч/т.
  Это формула 12 из [Hoffimann et al., 2022](https://doi.org/10.1007/s11004-022-10013-1),
  применённая к опубликованным M (г/об), A, F80, P80 (мкм). Не случайная твёрдость.
- Cu берётся из ближайшей пробы drillholes по евклидову расстоянию XYZ.
  Содержание ограничивается 10-м/90-м процентилями этих 60 значений, затем
  умножается на коэффициент до среднего 0,43%. Исходные ppm тоже сохраняются.
- LCT берётся из ближайшей пробы flotation с конечным LCT (52 из 53).
  Расстояния до обеих использованных проб сохраняются. LCT не масштабируется;
  его соответствие P80=150 мкм в нашей фабрике — допущение, не результат теста.
- BWi делится по медиане на 30 мягких и 30 твёрдых мест. На каждом забое
  план меняет место раз в 12 ч, сортировка по убыванию Z и затем X, с начальной
  фазой по сезону. Объёмы запасов и этот порядок отработки — модельные.
  «Твёрдая руда» выбирает место с максимальным BWi и повышает долю твёрдого забоя.
- XYZ источника сохраняются. Для схематической 3D-сцены XY равномерно
  масштабируются по максимальному размаху до 1,7 радиуса карьера, Z — на его
  глубину. Цвет вершин уступов соответствует ближайшей пробе в этих координатах.
  Белые маркеры показывают два текущих места добычи; маркеры видны сквозь уступы.

Это **не скважины Актогая, не оценка запасов и не полноценная блочная модель**.
Мы не воспроизводим Bayesian/Hilbert-Kriging из статьи: используем прозрачное
приближение ближайшей пробы. Пространственная неопределённость не оценена.
Смешение BWi по тоннажу — приближение аддитивной энергии, LCT по содержащейся
меди — приближение выхода; реальные нелинейные эффекты смесей не идентифицированы.
Начальные запасы заданы прежними номинальными анализами; новые свойства
проходят через склады с балансами и не подменяют свойства уже накопленной руды.
